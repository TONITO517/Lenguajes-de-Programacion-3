# Práctica 10: Java Swing avanzado

Lenguajes de Programación III - Universidad Católica de Santa María (UCSM), noviembre de 2026.

**Autores:** Vega Mamani, Anthony; Rocchetti Diaz, Bruno Valentino; Laurente Sihuayro, Jhoel Luis Fernando.

## Contenido

| Carpeta | Descripción |
|---|---|
| `actividades/` | Experiencia de práctica: binding de datos manual (`AppProducto`, `Producto`) |
| `ejercicio1_tienda/` | Ejercicio 1: gestión de un producto en una tienda (binding manual) |
| `ejercicio2_temperaturas/` | Ejercicio 2: gráfico de líneas de temperaturas semanales con `Graphics2D` |
| `ejercicio3/` | Ejercicio 3: botonera de efectos de sonido con `Clip` |
| `ejercicio4/` | Ejercicio 4: reproductor de música (reproducir, pausar y reanudar) |
| `informe/` | Informe de la práctica en formato Word |

## Cómo ejecutar

1. Crear un proyecto Java (JDK 11 o superior) en Eclipse y copiar las carpetas dentro de `src`.
2. Los ejercicios 3 y 4 leen los archivos desde una carpeta `sonidos/` ubicada en la raíz del proyecto, con los archivos WAV `aplausos.wav`, `campana.wav`, `explosion.wav` y `musica.wav`.
3. Ejecutar la clase con `main` de cada carpeta: `AppProducto`, `AppTienda`, `AppTemperaturas`, `BotoneraSonidos` o `ReproductorMusica`.
